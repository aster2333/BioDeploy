# Biodeploy

轻资产湿实验编排平台，为生成式生物学提供酶动力学与功能性实验真值数据。

**The physical bedrock for bio-intelligence: Converting wet-lab reality into fuel for generative biology.**

新定位来源：[New-intro.md](docs/New-intro.md)。目标包括动态酶动力学、底物特异性与多条件矩阵、高通量表达与溶解性，以及 ML-ready JSON / Parquet 数据。详细范围见 [PRD](docs/PRD.md)。

本轮同步文档、首页愿景、元信息和网络叙事。以下功能清单描述现有 v0.3 演示；三张核心服务卡与范围弹窗已按审核版实现；新报价计算器已支持 24–384 个变体、三类新服务和 Standard / Rush；新工作台仍待实现。

- 硅谷开发者平台风格的响应式首页：首屏、产品工作台预览、验证套餐、全球交付网络。

- 可切换的输入 / 实验 / 结果预览，四个合成候选及 Raw / Fit / QC 视图。
- 核心套餐为酶动力学、催化矩阵与表达质控；目标起价与前提见 [套餐审核](docs/PACKAGES_REVIEW.md)。
- 费用估算采用酶动力学 USD 110 / 变体、催化矩阵 USD 85 / 变体 / 六条件面板、表达质控 USD 35 / 序列的演示目标价；24–384 个变体，矩阵可选 1–4 面板。Standard 21 天 / Rush 14 天，Rush 演示加价 25%，不代表已核实商业报价或排期。估算与未发送询价 JSON 均可下载。

- 合成示例 JSON / CSV 下载，保留阴性、未表达与 QC 异常。
- 字体本地提供，运行时无第三方请求和生产依赖。
- 品牌 404 页面：四语言、返回首页与实验套餐入口，支持嵌套错误地址。

当前是网站外壳。真实上传、自动预检、商业报价、登录、下单和实验交付尚未实现。演示报价完全在浏览器本地计算，不是正式报价；支持配置、确认范围、填写邮箱和未发送的询价预览。邮箱不传输或持久化；主动下载的询价 JSON 含填写的邮箱，不提交实验。API 使用保留的 `.example` 域名，不调用网络服务。所有实验数据均为合成示例，地区图不表示已确认的实验室或可用容量。

## 本地运行

要求 Node.js 20 或更新版本，无需安装依赖。

```sh
npm run dev
```

访问 <http://127.0.0.1:4173>。如端口被占用：`PORT=4174 npm run dev`。

```sh
npm run check
npm run build
npm run preview
```

构建结果在 `dist/`，可部署到支持静态文件的网站服务。`preview` 和 `dev` 默认使用同一端口，先停止其中一个，或给另一进程指定不同的 `PORT`。

404 预览：访问 `/404.html` 或任意不存在的地址。本地开发 / 预览服务返回带品牌页面的 HTTP 404；缺失的脚本、样式与字体仍返回纯文本 404。静态部署时将站点的自定义 404 文档设为构建产物中的 `404.html`，保持 404 状态码，避免配置成返回 200 的首页重写。
