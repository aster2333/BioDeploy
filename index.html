How this demo is calculated

USD base rates at 96–191 sequences: $45 expression, $89 screening, $139 affinity. Quantity factors: <48 ×1.15; 48–95 ×1.08; 96–191 ×1; 192–384 ×0.92. Each replicate beyond two adds 45% of the base assay amount. Binding multiplies by target count. Rounded in cents.

Assay and delivery questions

How long does a run take?

This demo uses 21 calendar days from project confirmation for all packages. Target procurement and repeat measurements may add time. The schedule must be confirmed for a real project.

Can I order at these prices?

These are demo prices. The calculator downloads an estimate, but does not take payment or submit an experiment.

Screening or full characterization?

Screening uses two concentrations to rank binding. Characterization uses four to estimate Kd, kon and koff when the data passes QC. Some sequences will not yield reliable kinetic values.

What if a protein does not express or bind?

If expression is not detected, there may be no binding measurement. If a protein expresses but does not bind, that is a negative result. QC failures need review. Rerun fees and responsibilities must be agreed before a real order.

Will I receive physical protein?

The packages shown here deliver data. Protein samples, scale-up, shipping and target procurement are not included in the estimate.

Where will experiments run?

China, the US and Australia are planned delivery regions. Lab availability, data access and regional restrictions must be confirmed for a real project.

What can I try in this demo?

Compare sample results, download synthetic JSON or CSV, and estimate assay costs. Real sequence uploads, ordering and API access are not enabled.
