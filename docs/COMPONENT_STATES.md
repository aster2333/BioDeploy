## 3. 状态与交互矩阵

| 组件 | 必须覆盖 | 规则 |
| --- | --- | --- |
| 按钮 / 链接 | 默认、hover、pressed、focus、disabled、busy | 原生语义，44px 目标；忙碌时阻止重复触发并有文字；禁用有相邻可见原因 |
| 输入 / select / slider | 默认、focus、有值、invalid、disabled | 标签常驻；错误保留原值；input 与错误以 aria-describedby 关联；禁用控件不参与当前配置 |
| 套餐单选 | 未选、选中、focus、不可用 | 原生 radio，整行可点；标题与价格含义明确；不把不可购买能力标记为可用 |
| 步骤导航 / tabs | 当前、已访问、未到达、focus | step 用 aria-current，tab 用 aria-selected；tab 支持方向键和 Home / End；不能靠 CSS 模拟禁用 |
| 状态徽标 | 有效结合、未结合、未表达、待复核、演示 / 未发送 | 文本必需；科学阴性用中性，QC 用注意，系统失败才用红色 |
| 空状态 | 无数据、无匹配、未测量、无有效拟合 | 标题 + 具体原因 + 可执行下一步；保留用户条件与其它可用数据 |
| 操作反馈 | 准备中、已发起、失败、重试、关闭 | 独立于页面布局；信息用 polite，操作失败用 alert；不能宣称浏览器文件已保存 |
| 数据表 | 默认、当前行、选择、部分全选、无匹配、长内容 | 表头、caption、选中数；数值右对齐，null 为破折号；不把筛选后的零行当加载失败 |
| 批量操作 | 未选、部分选、全选、导出中 | 选择跨筛选保留并显示总数；全选只作用可见行；导出精确选中项，包含阴性及 QC 原因 |
| 对话框 | 打开、取消、完成、键盘关闭 | 原生 dialog、可读标题、焦点限制、Escape、关闭后还原焦点；只在确需决策时使用 |
| 加载容器 | 未开始、真实忙碌、完成、失败 | aria-busy 对应真实任务；减少动效下静止；本地即时计算不添加假进度或等待 |
| 响应式 | 360 / 768 / 1440px、200% 缩放 | 无整页横向溢出；表格 / 代码在自己的可聚焦容器内滚动；长邮箱与 ID 可换行 |

## 4. 报价错误与恢复

- 当前数量边界为 8–800 个蛋白质。空值、非整数、越界保留输入，显示具体范围，清空所有旧金额并禁用后续步骤与下载。滑轨 / 快捷值可用作恢复。
- 基础重复次数随服务变化：表达 / 结合为 2，热稳定性为 1。非当前服务的靶点 / 缓冲条件控件隐藏并禁用，已有服务独立配置继续保留。
- 错误状态以 errorKey 定位对应字段，不能将所有错误都标到数量上。每个非法字段具有 aria-invalid，错误区明确说明下一步。
- 邮箱首次输入不立即报错，失焦或尝试预览后校验，随后随输入恢复；不禁止粘贴。邮箱不进入 URL 或持久化存储。
- 未发送草稿使用中性状态，不显示“发送成功”；编辑后旧草稿失效。输入错误、语言切换与下载失败都不清空配置。

## 5. 科学结果异常与恢复

| 场景 | 展示 | 可做什么 | 不得出现 |
| --- | --- | --- | --- |
| 有效结合示例 | 原始曲线、拟合、示例 Kd、合成标记 | 查看 QC、下载 | 真实实验已验证的承诺 |
| 未检测到结合 | 中性结果、原因、原始曲线、Kd 为 — | 返回原始曲线或查看 QC | 红色系统错误、0 nM、虚构拟合 |
| 未表达 | 未测量空状态、未表达原因 | 查看 QC 与来源、保留导出 | 空白图框、虚构测量 |
| QC 待复核 | 琥珀提示、无有效拟合、Kd 为 — | 查看原始曲线或 QC | 可信拟合或删除异常候选 |
| 搜索无匹配 | 无匹配标题，当前搜索 / 筛选保留 | 清除条件 | 自动切换候选或清空选中记录 |

空态说明中可重复关键原因，避免用户从其它标签页寻找解释；正常结果不新增重复说明。

## 6. 下载与通知契约

共享实现：`src/ui-feedback.js` 与 `src/components.css`。

- `createFeedback({root,t})` 返回 `show(key,{tone,retry})` / `dismiss()` / `render()`；`tone` 为 info / success / warning / error。
- `createDownloadManager({feedback})` 的 `run({content,filename,type,button,successKey})`：content 为字符串或返回字符串 / Promise 的函数。返回 Promise<boolean>，不抛出可恢复错误。只允许一个下载准备任务；按钮 disabled 与 aria-busy 在 finally 恢复，错误不清空输入。
- 浏览器只能确认文件下载已发起。成功提示为“已发起下载”，不声称文件已保存；浏览器静默拦截无法由当前实现确认，用户可重试。
- 失败提示保持可见，给出重试 / 关闭。重试调用相同任务；报价 / 草稿下载执行时重新检查当前有效配置，不导出失败前的旧金额。
- 通知不自动夺取焦点；用户关闭时若焦点位于通知内部，恢复到触发器。信息与失败分别使用持久的 status / alert 区域。语言切换仅改文案，不清除恢复动作。
- 不添加网络、支付、登录或伪造后端发送。文案不记录邮箱、序列或内部异常堆栈。

## 7. 组件示例页与实现边界

`/components.html` 为独立内部示例页，首页不增加开发入口。共用生产字体、令牌、徽标、空状态与下载反馈。支持四语言，展示按钮状态、字段校验、深浅色科学状态、真实本地下载、明确标注的失败演练、原生弹窗及长表格。

表格示例复用合成数据扩展成 12 个带唯一 ID 的示例行，支持搜索 / 状态筛选、可见行全选、跨筛选选择与选中 JSON 导出。组件页的加载和模拟失败仅用于状态演练，明确标注；不把这些内部操作加入科学演示主流程。真实网络 / 鉴权 / 支付 / 生产空数据属于未来接入时的契约，当前不伪造这些服务。

## 8. 验收

1. `npm run check` / `npm run build` / `git diff --check` 通过。
2. 主页面：数量 7、空值、801、恢复 96；热稳定性 1 次重复 / 条件 4；三类服务切换保留输入；错误金额不残留。
3. 结果：四候选的 Raw / Fit / QC 状态正确；空态动作可用、键盘可达，异常导出保留 null 与原因。
4. 下载：正常发起、注入文件生成失败、点击重试恢复、关闭反馈、语言切换、重复触发不会重复执行。失败不能破坏邮箱 / 报价 / 草稿。
5. 示例表格：筛选无匹配、清除恢复、部分全选、筛选后选中数不丢失、导出只包含所选项。
6. 手机 / 平板 / 桌面四语言无整页溢出；减少动效、焦点环、对话框 Escape 与焦点返回有效。


## 9. 控件外观修正

- 信息型对话框底部的单个关闭操作右对齐；键盘关闭及焦点返回规则不变。
- 下拉框保留原生 select 交互，统一框内箭头与右侧 38px 留白，箭头不单独占据控件外的按钮区域。控件 max-width 为容器宽度，窄屏可收缩。
- 下拉框焦点使用框内 2px 蓝色轮廓（outline-offset: -2px），替代外扩的 3px 轮廓和 4px 间隔。键盘焦点仍可识别，选中后不产生大圈或额外视觉溢出。


## 10. 酶动力学目标状态

新工作台须区分未表达、无可检测催化活性、未测量、拟合失败与有效动力学。无活性不等于系统错误，缺失 kcat / KM / kcat/KM / R² 使用 null 与原因；不能复用 binder 的 Kd 作为催化指标。kcat 缺少活性酶浓度依据时不得显示可信数值。

Sequence & Substrates 校验序列和底物关联；Continuous Kinetic Traces 保留多浓度与原始单位；Fitted Parameters 展示拟合依据和 QC；ML Data Export 在 JSON / Parquet 文件实际生成后才提示已发起下载。保留阴性、对照、实验条件及批次，格式失败可重试且不丢输入。

目标计算器 24–384、四类 assay、Standard / Rush 各有独立字段错误；无效输入清空旧金额和数据点数。该目标尚未替代当前 8–800 演示契约，需随产品实现更新检查。现有可访问性、忙碌状态、重试与未发送询价规则继续适用。

## 11. 审核版套餐详情

`kinetics`、`matrix`、`expressionQc` 是独立范围键，文案在 `src/package-copy.js`。详情分别渲染输入、实验深度、技术重复 / 单培养、待确认排期、方法和输出。新套餐隐藏旧报价配置入口，避免误计为 binding 或错误套用旧 expression 价格。语言切换重渲染已打开详情；关闭返回原卡片按钮。
