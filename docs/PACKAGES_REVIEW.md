## 科学内容修正

1. **非线性回归为主。** 不把 Lineweaver–Burk 线性拟合作为交付参数的来源；倒数变换会改变误差结构。如客户需要，可额外展示基于非线性拟合的变换图。[GraphPad 方法说明](https://www.graphpad.com/guides/prism/latest/curve-fitting/avoidscatchard_lineweaver_burkeandsimilartransforms.htm)
2. **不无条件承诺“true catalytic efficiency”。** kcat = Vmax / 活性酶位点浓度；总蛋白或粗裂解液浓度不能自动充当活性酶浓度。缺少依据时交付表观参数及原因，不提供可信 kcat。Michaelis–Menten 不适用时不得强行拟合。[GraphPad 模型定义](https://www.graphpad.com/guides/prism/latest/curve-fitting/reg_michaelis_menten_enzyme.htm)
3. **连续读数并非普适。** UV/Vis / 荧光或耦联读数须确认兼容性、背景、初速线性区、检测范围与底物消耗；不支持光学读数的反应单独设计。pH 4.5–9.5 仅为可评估范围，pH 和温度也会改变探针 / 耦联酶响应。[Assay Guidance Manual](https://www.ncbi.nlm.nih.gov/books/NBK92007/)
4. **T50 是温度，不是速率。** T50 必须标注暴露时长、孵育与残余活性测定条件。失活速率常数需要多时间点实验，不能由一次温度梯度直接给出；T50 也不是 Tm。[热失活原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3953309/)
5. **相对选择性不等于催化效率比。** 单浓度底物面板可比较指定条件下活性，不能自动推出各底物的 kcat/KM 比值。完整特异性常数需要逐底物动力学与相应定量依据。
6. **表达结果是检测限内判定。** mg/L 定义为每升培养液的估算目标蛋白产量，不是纯化产量或活性浓度。按标准品校准、记录背景；条带身份 / 分离不明确时不声称精确产量。Pichia 与 capillary 不纳入 $35 基础包。

## 价格证据与边界

- [UCLA 表达核心设施](https://www.doe-mbi.ucla.edu/expression/)公开列出一个 96 孔表达纯化流程及外部价格 $2,927.52，但其说明限制菌株 / 质粒组合最多为 8。不能除以 96 后当作 96 个不同序列的市场报价。仅用于说明批量流程和范围约束的重要性。
- [GenScript 合成页](https://www.genscript.com/gene_synthesis.html)将基因合成 / 克隆作为独立计价服务；因此 $35 表达 QC 和 $110 kinetics 不能默认为从 FASTA 起包含 DNA 制备的全包价。
- [Sino Biological 酶服务](https://www.sinobiological.com/quote/enzyme-profiling)采用定制询价。未找到与本矩阵范围完全相同、足以验证 $110 / $85 / $35 的公开报价。

商业报价前应取得实际样品量、底物价格、样品准备与 assay setup 成本、读板与分析人工、对照 / 失败 / 复测成本，并按可交付变体数计算单价与毛利。96 variants 不等于 96 孔：动力学基础测量至少 96 × 8 × 3 = 2,304 个样品反应孔，另加对照；矩阵至少 1,728 个样品反应孔。三次技术重复不包含三批独立表达。
