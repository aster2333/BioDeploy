# Biodeploy 产品需求文档

版本：0.3 · 阶段：专业产品演示外壳 · 更新：2026-10-24

## 1. 产品定位

Biodeploy 将 AI 设计的蛋白质序列转化为结构化湿实验验证数据，通过跨国家实验室网络交付。目标用户是计算生物学家、AI 蛋白质研究人员、高校研究者和 AI 生物科技团队。

核心定位：快速、AI-native、交付范围明确且迭代成本可负担的实验基础设施。Sequence-in, Data-out、API 和速度属于同类产品基础要求；差异应由适配的标准化套餐、明确边界、预算透明度与跨实验室质量治理支撑。更便宜是待成本验证的商业目标，当前不发布未经验证的竞品价差或节省比例。

## 2. 本阶段范围

本阶段交付完整、可本地运行的多语言演示外壳，无后端交易。

包含：
- 品牌首页、响应式导航、四语言切换与偏好保留。
- 输入 / 套餐 / 结果工作台，合成候选对比，原始曲线、拟合、QC 视图。
- 表达与结合套餐规格、结合初筛与亲和力表征的明确区分。
- 本地演示报价器，明细与总额联动；配置、确认范围、邮箱三步询价预览，可下载演示估算或未发送的询价草稿。
- 可检查的实验里程碑、阶段责任与预计周期。
- 中国、美国、澳大利亚交付模型；统一规格、来源记录与交付责任说明。
- API 请求 / 事件示例及数据字段说明，全部注明未上线。
- 科学结果、价格、数据和失败处理 FAQ。

不包含：真实上传/解析、预测、实验下单、支付、账户、真实 API、webhook 发送、实验室路由、真实容量、真实客户案例。演示不产生订单号或收取付款；邮箱仅在当前页面填写、校验和预览，不传输或持久化。用户明确下载询价草稿时，下载文件包含填写的邮箱。

## 3. 页面与访问路径

页面顺序：品牌首屏 → 能力条 → 产品工作台 → 套餐规格 → 演示报价 → 实验里程碑 → 全球网络与治理 → API / 数据契约 → FAQ → 收尾。

主 CTA 为“配置演示”，进入演示报价器；次 CTA 为“查看示例数据”，打开结果视图。套餐卡可打开完整范围，或带入报价器。任何价格、周期和配置结果附近都显示演示标识。

用户能完成：了解交付范围 → 配置预算 → 查看时间构成 → 检查数据质量 → 下载合成数据或演示估算。所有行为只在浏览器本地发生。

## 4. 套餐与交付规格

| 标识 | 范围 | 数据 | 演示基础单价 / USD | 演示周期 |
| --- | --- | --- | --- | --- |
| expression | 表达初筛；具体表达体系待确认 | 表达分类、相对读数、示例 QC | 45 / 序列 | 21 个日历日（演示） |
| screening | 表达初筛 + 结合初筛；2 个非零浓度 | 结合分类、响应排序、曲线、QC；不提供精确 Kd | 89 / 序列 | 21 个日历日（演示） |
| affinity | 表达初筛 + 亲和力表征；4 个非零浓度 | 条件允许时的 Kd / kon / koff、原始曲线、拟合与 QC | 139 / 序列 | 21 个日历日（演示） |
| thermostability | 表达初筛 + 按缓冲条件的热稳定性测量；具体方法待确认 | 热熔解曲线、通过 QC 时的 Tm 估值与测量质控 | 99 / 序列 / 条件 | 21 个日历日（演示） |

基础单价对应 96–191 条序列；表达与结合含 2 次重复，结合套餐按 1 个靶点；热稳定性含 1 次测量，按 1 种缓冲条件。上述数字是用户授权的演示数据，不是市场报价、可购买服务或 SLA。

E. coli 只描述候选体系方向，不能默认推断整细胞或无细胞。产品中标注具体体系待确认，不声称与竞品的方法等同。默认演示仅交付数据，不含蛋白实物、靶点采购、税费和运输。

## 5. 演示报价契约

纯计算模块：`src/quote.js`，不依赖浏览器 DOM。

输入：`{ mode, quantity, replicates, targets, conditions = 1 }`。
- mode：expression / screening / affinity / thermostability；service 为 expression / binding / thermostability。
- quantity：整数 8–800；输入框与原生滑轨双向联动，提供 24 / 48 / 96 / 192 / 384 / 800 快捷选项。
- replicates：表达与结合为 2 / 3 / 4，基础价含 2 次；热稳定性为 1 / 2 / 3 / 4，基础价含 1 次。
- targets：结合模式 1 / 2 / 3；表达与热稳定性始终规范化为 1。
- conditions：热稳定性缓冲条件数量 1 / 2 / 3 / 4；其他服务始终规范化为 1。
- 币种固定 USD，语言与地区不会改变报价币种或价格。

规则：数量 <48 系数 1.15；48–95 为 1.08；96–191 为 1；192–800 为 0.92。基础单价按美分四舍五入。每超出套餐基础次数增加一次重复，在基础实验金额上增加 45%。靶点数为结合实验乘数，缓冲条件数为热稳定性实验乘数。全部金额以整数美分计算，格式化用当前 locale 的 Intl.NumberFormat。

输出：`synthetic: true`、`not_a_quote: true`、规范化配置、单价、基础实验金额、额外重复金额、总额和演示周期。无效输入返回错误，隐藏旧总额并禁用下载，避免继续显示看似有效的估算。输入框不会在每次按键时强行改成边界值。

费用摘要提供“下载估算文件”。主流程依次进入范围确认和邮箱填写，最终操作为“预览询价内容”；完成态说明未发送，并允许下载询价草稿。不得出现“已下单”、虚假发送成功或支付表单。

## 6. 科学数据契约

`src/sample-data.js` 是图形、表格、JSON 与 CSV 的唯一示例来源。

候选覆盖：
- binder_001：合成的有效结合示例，允许展示示意 Kd。
- binder_002：表达可检测但未检测到结合，Kd 为 null。
- binder_003：未表达，未进行结合测量，曲线为空，Kd 为 null。
- binder_004：测量存在但拟合未通过 QC，Kd 为 null。

每条候选包含状态、原因、方法、时间/响应单位、演示批次/方法标识、原始 traces、拟合 traces、示例 QC。`qc.synthetic` 必须为 true。真实实验不由这些示例推断。

原始/拟合/QC 视图在候选切换时保持选择；不可用拟合时显示原因，不编造数值。初筛套餐说明明确不承诺精确 Kd。导出保留 null、原因、单位、原始数据、拟合与来源，不将 null 编码为 0。CSV 保留所有候选，即便无测量也以空值行和原因保留；每个 trace 行标明 raw / fit。

## 7. 里程碑与交付治理

五阶段：范围确认 → 材料准备 → 蛋白表达 → 测量 → 质控与数据发布。页面选择阶段只是查看说明，不模拟真实生产或倒计时。显示预计周期是示意，不保证真实排期。

网络治理采用拟定原则：统一套餐规格与方法版本；每个结果保留地区、实验来源、仪器与批次记录；按方法和对照评估可比性；由平台统一协调异常。统一 JSON 不等于实验结果天然可比。

交付网络按用户提供的供应商名单展示瑞士 Adaptyv Bio、新加坡 GenScript、美国 Twist Bioscience，仅展示名称，不附官网链接；中国保留同格式地区标签与待补充面板，其他地区后续补充。不额外声明独家合作、容量、认证或实时运行状态。数据访问、保留、使用、跨地区约束与复测计费需在真实项目确认。

## 8. API 与文档预览

展示 POST 请求与结果事件的拟议契约。域名采用保留 `.example`，例如 `https://api.biodeploy.example/v1/experiments`，明确“API 设计预览，尚未上线”。代码可切换查看，不发起请求，不创建任何实验。

输入展示序列引用、套餐、预算上限和需人工确认；事件展示版本、结果状态、QC 和数据引用。技术标识保持英文，解释性文案全部本地化。不得声称已集成第三方平台或已有可调用 API。

## 9. 国际化与可访问性

语言：en / zh-CN / zh-TW / ja。默认英文；手动选择优先并保留。语言自称展示，不用国旗。语言、地区、候选、数据视图、报价配置、里程碑与代码视图独立，切换语言不重置。

所有标题、价格标识、表单标签、错误、结果原因、FAQ、弹窗、图形和无障碍提示都有四语言文案。技术键、文件名、单位保持英文。数字与货币按语言格式化，币种不变。

键盘可操作标签、表单、菜单和弹窗；错误与总额变化通过适当 live region 提示。360 / 768 / 1440px 无整页横向溢出；代码、表格只在自身容器滚动。尊重减少动效偏好。

## 10. 验收与验证

- 国际化键完整，动态文案同样校验。
- 报价默认值、数量边界、模式切换、重复和靶点乘数有可执行断言；空值、分数、非数字、越界输入不能生成估算。
- expression 不残留靶点倍数；切换语言/地区不改变总额。
- 负结果不显示精确 Kd，未表达不生成测量曲线，QC 失败不生成可信拟合。
- 图形和导出读取相同数据；估算与数据导出均带演示标记。
- 页面不发出交易、研究数据上传或第三方 API 请求；无付款或个人信息传输；邮箱只在当前页面及用户主动下载的草稿内。
- 静态构建通过，实际浏览器验证主要路径与响应式。

## 13. 询价演示契约（2026-10-25）

用户确认本轮先做完整可操作演示，包含邮箱填写与校验，不接真实接收后台。本轮用户已明确新增热稳定性服务演示。服务入口为表达、结合、热稳定性；结合下再选择初筛或亲和力表征。原有三个范围的基础价不变，所有数量上限改为 800；热稳定性演示基价为 USD 99 / 蛋白质 / 缓冲条件，按 96–191 个蛋白质及 1 次测量计算。全部演示周期仍为 21 个日历日。蛋白质数量按一个设计序列对应一个候选计数。

- `src/quote-flow.js` 负责三个步骤及预览，`src/inquiry.js` 负责邮箱验证与可导出的草稿。
- `validateInquiryEmail(value)`：去除首尾空白，校验本地部分和至少两段的域名；拒绝缺失地址、空白、连续本地点、非法域名及超长地址；不校验邮箱所有权或可投递性。
- `createDemoInquiry(configuration, email)`：重新计算并验证费用。无效输入返回 `{valid:false,errorKey}`；有效返回 `{valid:true,schema_version:'1.0',synthetic:true,not_a_quote:true,status:'draft_not_sent',contact:{email},estimate}`。
- 费用摘要的估算下载不包含邮箱；“下载询价文件”下载 `biodeploy-demo-inquiry.json`，包含邮箱与规范化估算，无订单号、发送时间或虚假回执。
- 邮箱不进入 localStorage / sessionStorage / URL，不发起网络请求。刷新丢弃草稿；切换语言保留当前状态。
- 参数错误时清空旧费用、禁用前进与下载；表达模式规范化靶点为 1。返回修改保留输入，修改后废弃旧预览。
- 验收覆盖空邮箱、非法邮箱、合法邮箱、非法数量、表达模式、结合初筛范围、额外重复与靶点计价、步骤返回、四语言状态保留及下载内容。


## 14. 服务切换与数量滑轨（2026-10-25）

服务表单与价格引擎共同支持三类服务、四种 mode。服务切换在当前页面内独立记住数量、重复次数、靶点 / 缓冲条件，以及结合实验深度；不持久化。表达仅显示数量与重复，结合额外显示初筛 / 表征和靶点，热稳定性额外显示缓冲条件。无关参数在估算 JSON 中规范化为 1，避免靶点或条件残留产生错误计费。

`demoCatalog` 为每个 mode 提供 service / includedReplicates / baseUnitCents / methodKey / nameKey / scopeKey / days。估算输出保留 service、mode、quantity、replicates、targets、conditions 和 included_replicates。热稳定性方法为拟议 nanoDSF，不声称实际支持全部蛋白格式、已建立仪器能力或一定取得有效 Tm。

数量输入框和 input[type=range] 均为 min=8 / max=800 / step=1。滑轨 input / change 立即更新输入框与价格；有效手输同步滑轨。空值、分数或越界手输不被强制改写，价格清空并阻止下一步与下载；滑轨停在上一个合法位置，用户移动后可恢复有效配置。支持键盘方向键、Home / End 和触摸拖动。

验证基准：热稳定性 96 个蛋白质、1 次、1 条件为 950400 美分；2 次、2 条件为 2756160 美分；800 个、4 次、4 条件为 68492160 美分。表达 800 个、2 次为 3312000 美分。801、分数及非法条件数必须拒绝。
