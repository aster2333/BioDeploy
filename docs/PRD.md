# Biodeploy 产品需求文档

版本：0.1 · 阶段：品牌网站外壳 · 更新：2026-10-24

## 1. 产品定义

Biodeploy 将 AI 生成的蛋白质序列转化为可供计算工作流使用的湿实验验证数据。核心模型是 Sequence-in, Data-out：提交 `.fasta` / `.pdb`，选择标准化验证套餐，了解价格和预计周期，由跨国家实验室网络交付结构化数据。

目标用户：AI 蛋白质研究人员、计算生物学家、生物信息学研究人员、大学博士/博士后、AI 生物科技初创团队。

品牌定位：面向研究者的实验基础设施。界面应像现代开发者平台一样清晰、精确、有可信度，避免传统医疗机构网站的视觉语言。

## 2. 本阶段目标与边界

交付可本地运行、响应式、多语言的品牌网站外壳，并建立后续产品开发的设计和内容契约。

### 本阶段包含

- 完整的品牌首页、桌面与移动导航、右上角语言菜单。
- 英文、简体中文、繁体中文、日文四种完整界面文案；默认英文，手动选择优先。
- 语言选择持久化；刷新保持选择，更新页面 `lang`、标题、描述及无障碍标签。
- Sequence → Assay → Dataset 的视觉叙事与三个可切换的静态产品预览状态。
- 两个标准化套餐的介绍与可打开的详情弹窗。
- 中国、美国、澳大利亚三个交付地区的介绍视图，清楚标注网络为示意展示。
- 示例 JSON、CSV 下载，仅含本地合成数据。
- 设计规范、参考来源和本地运行说明。

### 不包含

真实文件上传、序列解析、开发性预测、实时报价、下单支付、登录、实验室路由、实验履约、真实实验数据、真实实验室容量与在线状态。外壳中的静态预览不改变这些边界。

## 3. 页面架构

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 顶部导航 | 品牌、平台、套餐、全球网络、语言菜单、查看平台 | 锚点跳转；移动端折叠菜单 |
| 首屏 | Sequence in. Discovery out.，价值说明，主次 CTA | 主 CTA 到平台；次 CTA 选中结果预览并定位 |
| 首屏图形 | 序列卡、验证流程、结合曲线、数据文件 | 用真实可读的示例内容解释产品；全部标明示例 |
| 能力条 | 标准化实验、结构化输出、全球交付 | 描述能力方向，不放编造的客户或统计 |
| 平台预览 | 深色工作台，Input / Assay / Results | 切换示例状态；结果里提供示例文件下载 |
| 套餐 | Starter Expression / Binder Assay | 详情弹窗解释套餐范围；不展示未经确认的价格或周期 |
| 全球网络 | 中国、美国、澳大利亚；地区选择器 | 仅更新地区介绍；不宣称具体实验室已上线 |
| 收尾和页脚 | 品牌口号、返回平台、阶段说明 | 回到预览；展示版权和示例说明 |

## 4. 核心访问路径

1. 访问者在首屏理解“提交序列，获取验证数据”。
2. 点击探索平台，在同一页查看输入、实验范围、结果三个示意状态。
3. 查看两个套餐的区别与交付物，打开详情了解范围。
4. 了解跨国家交付网络，并下载合成示例，理解未来数据接口。
5. 在任意位置切换语言，保留当前预览阶段与地区选择。

## 5. 国际化与交付地区

语言与地区必须是独立维度。选择中文不能自动路由到中国实验室；选择澳大利亚地区也不能改写用户语言或币种。

### 语言

| 标识 | 自称 | HTML lang |
| --- | --- | --- |
| en | English | en |
| zh-CN | 简体中文 | zh-CN |
| zh-TW | 繁體中文 | zh-TW |
| ja | 日本語 | ja |

使用自称，不使用国旗代表语言。菜单支持键盘打开、原生选项导航、Escape 关闭与焦点恢复。移动端仍放置在导航右侧。

文案集中于 `src/locales.js`。所有语言具备相同键集；布局不依赖英文的固定字符长度。蛋白质序列、JSON 字段名、文件名、单位保持原样；可见的导航、标题、辅助说明、提示、按钮、弹窗和无障碍标签全部翻译。`localStorage` 不可用时，切换在当前会话中仍正常工作。

当前默认语言为英文，不根据 IP 推断语言。未来增加 `/{locale}/` 路由和独立 SEO 页面时保留此键结构。当前静态外壳不宣称已完成多语言搜索引擎索引。

### 地区

中国、美国、澳大利亚是用户给出的交付网络示例。当前只介绍网络模型，明确显示“网络示意”，不得展示虚构的合作实验室、容量、认证或运行状态。

后续需求：地区可用性、实验能力、样品/数据跨地区约束、当地工作日、货币税费、统一 QC、可追溯实验记录及真实合作方信息。上述内容需要业务确认后实现，不能由前端假设。

## 6. 科学内容与信任

- 所有曲线和测量值都属于合成示例，不是实验结果。
- FASTA 是示例输入；PDB 在未来支持时应独立处理链信息与可用元数据。
- pLDDT 属于预测信息，只在有来源时展示；不得从任意上传文件虚构。
- Kd、kon、koff 仅在相应分析方法适用时出现，单位与 QC 必须随数据保留。
- Tm 仅在有对应实验时展示，不混入表达或结合套餐的默认结果。
- 后续实时报价必须包含币种、数量、价格依据、附加项、周期假设与总额；本阶段不编造商业价格。
- 不使用虚构客户 Logo、推荐语、成功率、实验室数量和安全认证。

## 7. 后续产品阶段

P1：真实输入与格式检查、套餐配置、透明报价与确认。

P2：实验提交、订单追踪、实验室履约与带时间戳的状态。

P3：真实结果查看、原始曲线/QC/批次元数据、结构化导出与 API。

外壳应为这些能力保留信息结构，不提前模拟交易成功或真实履约。

## 8. 验收标准

- 本地启动不依赖第三方运行时服务；构建得到可静态部署的目录。
- 四种语言键集一致，无缺失文案或 `undefined`。
- 从默认英文切换任意语言后，全页面和弹窗更新；刷新保留偏好。
- 语言菜单可键盘操作，关闭后焦点回到触发器。
- 首屏两个 CTA、导航锚点、预览切换、地区切换、套餐详情与下载均有真实行为。
- 弹窗可用关闭按钮、Escape 和遮罩关闭；焦点不能逃逸，关闭后恢复。
- 360px、768px、1440px 下无页面横向溢出；代码和表格在自身容器内滚动。
- 减少动态效果偏好生效；主要交互有清晰的键盘焦点。
- 页面没有发出上传、支付、下单、实验执行或提交研究数据的网络请求。
- 不把网站语言当作交付地区，不把网络示意当作已确认实验室。

## 9. 待业务确认

真实定价与币种、套餐最终范围和 SLA、合作实验室与区域可用性、实验失败处理规则、数据保留与隐私条款、品牌商标与公司主体。本阶段不以占位链接伪装这些内容已就绪。
