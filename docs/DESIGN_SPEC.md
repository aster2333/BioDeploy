# Biodeploy 设计规范

版本：0.3 · 更新：2026-10-24 · 适用：专业产品演示外壳

## 1. 设计概念

**Programmable discovery / 可编排的发现。** 将实验能力呈现成研究者可以理解、配置、追踪的数据基础设施。

以 Vercel 的布局、黑白层级与开发者清晰度为主要参考。以代码、序列和实验曲线解释产品。浅色品牌页面与深色产品工作台形成对比。品牌必须有自己的序列图形和输入输出叙事，不直接复制参考产品。

## 3. 品牌与标志

- 名称：正文用 Biodeploy；标志使用小写 `biodeploy`。
- 标志图形：三组短线/节点构成从序列到输出的流向，形成可缩小的 B 形符号。
- 图标与文字间距 9px；标志周围至少保留图形宽度一半的净空。
- 深色背景上反白，浅色背景上使用主文字色。
- 首屏标题：Test your protein designs. / 验证你的蛋白质设计。
- 核心利益说明：将 AI 生成的序列转化为结构化湿实验验证数据。营销短句不替代科学交付描述。

## 5. 排版

- 主字体：Geist（随站点提供）；失败时回退系统 sans-serif。
- 代码字体：Geist Mono（随站点提供）；失败时回退 SFMono-Regular / Consolas / monospace。
- 中文、繁体、日文回退到各平台的原生 CJK sans-serif，避免 Latin 字体造成缺字。
- 英文首屏标题 76–88px，字重 500–600，行高约 1.04，负字距；移动端 48–56px。
- CJK 首屏使用单独类控制字号与行高，保持语义换行，不强制英文断行。
- 区块标题 38–48px，移动端 30–36px。
- 正文 15–18px，行高 1.6；辅助文案 12–14px。
- 代码和指标 11–13px，使用等宽字体及 tabular-nums。
- 标题尽量 balance；正文不使用全局负字距。

## 6. 布局与表面

- 页面最大宽度 1240px；桌面左右留白至少 40px，移动端 20px。
- 以 4px 为基础间距；常用 8/12/16/24/32/48/64/96。
- 首屏桌面为文字与产品图形两列；900px 以下改为单列。
- 一级区块之间 96–120px，移动端 64–80px。
- 普通面板圆角 12px；小控件 6px；CTA 可使用 capsule。
- 细边框与低对比背景表达分组，减少大阴影。
- 深色工作台是整页的主要视觉锚点；内部控件密度高于营销区块。
- 不使用无意义的通用六宫格、玻璃背景层叠或装饰性巨型发光球。

## 7. 组件契约

### 导航和语言菜单

桌面品牌左、分区导航中、语言与主 CTA 右。移动端保留品牌、语言入口、菜单按钮。固定导航有明确底边界，锚点预留导航高度。

语言入口使用地球图标及当前语言自称，按钮需暴露展开状态。弹出层使用原生 radio 选项；支持 Escape、点击外部关闭及焦点恢复。语言改变后更新页面 `lang` 与元信息；不重置产品预览和地区状态。不得用国旗选择语言。

### CTA

主按钮深底白字；深色区域反白。次按钮透明或白底细边框。图标右置，hover 使用轻微底色或位移；active 有明确反馈。触摸目标至少 44px。

### 产品预览

使用三步切换控件：输入 / 实验 / 结果，`aria-selected` 与键盘方向键同步。显式显示“产品预览”和“示例数据”。只展示预设数据，无真实上传入口或伪造处理进度。结果区新增候选选择、原始/拟合/QC 视图和异常解释。

### 套餐

两张并列卡，共用名称、描述、范围、输出、详情入口。价格使用明确标注的演示数据，并注明基础数量、币种、重复与交付范围；不冒充正式报价或“免费”服务。详情弹窗是内容补充，不是订单确认。

### 地区选择

展示国家/地区名称、地理示意和协议说明。国家用来表示交付网络；地区与语言单独存储。明确“网络示意”，不将未确认合作方显示为运营中的实验室。

### 结果图形与导出

坐标、单位、图例、候选 ID 和合成数据说明需要可读。不同曲线可用色彩与线型双重区分。JSON 字段名保持英文，便于机器读取；所有解释性标题随语言变化。导出包含 `synthetic: true` 及单位，不把静态页面时间当作实验时间。

### 弹窗

使用原生 `<dialog>`，限制焦点，Escape 关闭，关闭后恢复触发器焦点。打开期间锁住背景滚动。窄屏对话框保留页边距与内部滚动。

## 8. 动效与可访问性

- 150–220ms 的交互过渡；只动画 opacity / transform 等轻量属性。
- 尊重 `prefers-reduced-motion`，取消连续动画和滚动动效。
- 提供跳到正文链接，语义化标题、section、nav 和 footer。
- 普通正文对比度至少 4.5:1，核心图形和控件边界至少 3:1。
- 所有可点击元素使用原生 button / a，不用 div 伪装按钮。
- 页面缩放与长译文不应截断操作；代码和数据区域局部滚动。
- 示例 SVG 提供可本地化的可访问名称，装饰性图形 `aria-hidden`。

## 9. 实现约定

本阶段采用静态 HTML、CSS、ES Modules，无生产运行依赖。入口 `index.html`；逻辑 `src/app.js`；文案 `src/locales.js`；样式 `src/styles.css`；本地字体 `public/fonts/`。

主题、字号、尺寸和颜色集中为 CSS 变量。地区与预览是页面状态，locale 是单独持久化偏好。禁止通过插入用户提供的 HTML 渲染内容；可见静态翻译通过 `textContent` 设置。

验证命令在 README 中提供。后续迁移 React / Next 等框架时保留本文件的语言键结构、视觉令牌和行为验收。


## 10. v0.2 竞品研究后的设计扩展

保留 Vercel 主方向与现有浅色品牌页 / 深色工作台、Geist 字体、黑白层级和蓝色交互。此次增加的是交付信息和可检查的产品逻辑，不重新设计品牌，也不复制 Adaptyv 的自动化实验室插画。

### 信息顺序与密度

首屏承诺 → 工作台与数据 → 套餐规格 → 演示报价 → 实验里程碑 → 全球网络与治理 → API/数据契约 → FAQ。每区承担一个明确决策任务。新增说明以紧凑表格、定义列表、行式时间线和真实内容填充，避免重复营销卡片。

### 演示标识

价格区、套餐数字、周期、数据、API 都在靠近相关内容的位置显示对应标识：演示估算 / 合成数据 / 拟议工作流 / 尚未上线。标识采用蓝色浅底或中性色边框，不用绿色表示已验证服务。价格是信息，主操作仍为黑底或深色工作台内反白。不得让脚注成为唯一的演示说明。

### 报价组件

桌面采用约 60/40 双列，左为原生表单，右为明细和总额。套餐有表达、结合初筛、亲和力表征三个模式；数量用快捷值和精确数字输入，避免只靠滑块。重复和靶点用有标签的原生 select。表达模式禁用不适用的靶点项，标签注明适用实验。

总额使用等宽数字、当前语言货币格式。错误与输入关联，错误时显示破折号并禁用保存。估算随输入更新，保存仅下载 JSON。报价区不出现支付、提交实验、成功订单、供应商 Logo 或虚假折扣比较。

### 结果组件

在深色工作台增加候选 select 与 Raw / Fit / QC 标签，控件为 44px 触摸目标。图形与候选摘要同步，单位始终可见。表格展示表达、结合判断、Kd 与示例 QC。只有有效示例展示数字；未知值使用破折号并附原因，不显示 0 nM。

状态使用文字和图标双重编码：通过用绿色、待核查用琥珀色、无结果用灰色；未结合是科学结果，不使用系统报错红色。QC 未通过时可看原始曲线，但不展示有效拟合。未表达显示明确空状态。QC 面板列出原因、方法/批次、合成指标，不以漂亮曲线代替质量说明。

### 套餐详情

采用定义列表显示输入、方法、浓度点、重复、数据文件、周期与限制。表达体系明确待确认；“初筛不交付精确 Kd”靠近交付项。套餐可带入演示配置，弹窗关闭后将焦点送往报价标题。

### 里程碑

5 个阶段采用横向细线与编号，窄屏改为纵向列表。当前选中只表示用户正在阅读的阶段，不表示实验正在运行。阶段详情包含工作内容、责任方和示例时间窗；无动画进度条、虚构实时状态或倒计时。

### 网络治理

沿用球面地理图与地区切换，新增横向规则区：规格、来源、质量判断、统一协调。文案描述拟议模型，明示合作与可用性待确认。不给用户制造选择实验室、比较供应商报价的负担。语言、地区与报价仍独立。

### API、FAQ 与信任

API 采用轻量代码面板，Request / Event 标签可切换；使用保留 `.example` 域名并说明未上线。代码可读、局部滚动，解释性文字四语言齐全。FAQ 使用原生 details/summary，回答数据、范围、异常、地区和演示限制。技术说明可帮助购买判断，不展示实现栈。

没有真实客户证据时，以可检验的样例、规格和方法建立可信度。禁止虚构案例、认证、实验成功率和合作标识。

### 工程约定

`src/quote.js` 为纯报价逻辑；`src/sample-data.js` 提供候选、曲线和导出；`src/experience-copy.js` 提供新增四语言文案，合并到既有 locale 字典。全部使用既有静态架构，无运行时外部依赖。修改语言只重新渲染文本与数字，不重置配置和页面状态。


## 11. v0.3 文案规范

沿用现有视觉，不通过“未来、发现、赋能、闭环、统一契约”等抽象表达营造科技感。每个区块标题说明功能，正文补充输入、实验、输出或限制；按钮写动作与对象。表达/初筛/表征、原始/拟合/QC 等必要分类可以并列，不为了排比强行凑句。

示例：
- Your next experiment. Already taking shape. → Inspect the result files
- Clear scope. Visible cost. → Estimate assay costs
- Your workflow. A shared data contract. → Submit sequences. Retrieve results.
- 少一些阻碍，多一些发现。→ 费用估算

中文、繁体和日文按当地科研/界面语境写，避免照搬英语断句与修辞。专业术语和机器字段保持稳定。价格、合成数据和未上线 API 的标识要靠近对应内容；不在每一段重复整套免责说明。

21 个日历日是演示预计周期，首屏与报价等处使用同一数字。里程碑用“第 1-5 天”等时间窗，不把 Day 0 显示成“0 个日历日交付”。真实项目起止与额外采购/复测时间需确认。

参考：Refero 文案指南的清晰度与操作原则；[Enode 开发者页面](https://refero.design/pages/a6941ca4-29a0-41d8-81ad-d7017e360055)的说明性标题；[Resend](https://resend.com/)明确的对象与用途；[Adaptyv 服务页](https://www.adaptyvbio.com/services/binding)将方法、周期与交付物放在一起。

## 12. 当前界面精简约定

区块保留一个清晰标题，删除重复副标题、眉题、补充说明条与装饰性能力栏。语言菜单只显示语言选项，不解释语言与地区、实验室或币种的关系。按钮名称已说明的动作不再另加提示段落。

工作台删除侧栏说明、底部状态条与重复导出说明；套餐删除重复提问和脚注；报价删除重复演示栏、公式行与下载说明；流程删除重复周期提示；网络删除治理卡片；API 删除解释卡片与重复未上线脚注；删除收尾报价引导。同步移除容器、占位间距、未使用样式与四语言文案键。

必要的信息直接放在相应内容里：示例/演示/API 状态用短标签，数量范围放入字段标签，套餐方法与交付范围保留在规格里。输入错误和异常结果保留具体原因，正常结果不额外显示重复说明。此约定取代前文对应的说明栏设计。


### 首屏图与套餐标识精简

首屏流程图删除四角的编号、工作流标签、流程文字与加号，只保留序列卡、结果卡及蓝色 B 节点。B 节点不附文字标注，节点中心与连线共用容器宽度 86%、高度 50% 的坐标，在桌面和窄屏保持对齐。套餐卡片顶部只保留图标，删除 EXP-01 / BND-01 装饰编号。

## 13. 报价与询价预览（2026-10-25）

参考锁定：保留当前 Vercel 主方向、Geist / Geist Mono、黑白层级与蓝色选中态，不重做品牌。主布局参考 [TwelveLabs 费用计算器](https://refero.design/pages/85938cf9-2030-43e3-93e8-314a43541460)：配置在左、持续可见的费用明细在右。参考 [Adaptyv Binding](https://www.adaptyvbio.com/services/binding) 的套餐单选、数量、重复和靶点联动及费用拆解；[服务目录](https://www.adaptyvbio.com/services)仅作服务组织参考。不沿用竞品价格、容量限制、方法承诺、公开数据折扣或客户标识。

| 设计决策 | 来源及采用范围 | Biodeploy 适配 |
| --- | --- | --- |
| 套餐以单选列表直接呈现 | Adaptyv 的 assay resolution 配置 | 保留表达、结合初筛、亲和力表征三个现有范围 |
| 配置与费用摘要双列 | TwelveLabs 的配置 / summary 关系 | 桌面摘要随滚动可见，移动端单列 |
| 参数分组、明细与总价同步 | Adaptyv 费用配置 | 继续使用整数美分规则，表达模式禁用靶点，错误时清空金额 |
| 三步配置、确认、邮箱 | 本轮用户要求 | 费用先可见，邮箱在最后；可返回修改 |
| 演示与未发送状态 | 用户明确选择演示 | 邮箱就地提示，完成态为“询价预览已生成” |

固定步骤：配置实验 → 确认范围 → 填写邮箱。后续步骤在到达前禁用；步骤变化将焦点送至标题，减少动效偏好下直接定位。确认页包含方法、数量、重复、靶点、范围与排除项。摘要始终显示 USD、基础实验、额外重复和总额，单位在表达模式去掉靶点。套餐卡单价注明 96–191 个蛋白质；表达和结合含两次重复，热稳定性含一次测量、一个缓冲条件，不能被理解为所有数量的固定单价。

邮箱使用可见标签、autocomplete=email、就地错误；错误在失焦或尝试预览后显示。合法邮箱只生成当前页面内的草稿，用户可明确下载含邮箱的 JSON。未发送预览用中性文件图标与文本，不模拟真实发送成功。所有状态四语言齐全，切换语言保留配置、步骤、邮箱和草稿；用户修改参数或邮箱会取消旧预览。


## 14. 三类服务与数量滑轨（2026-10-25）
